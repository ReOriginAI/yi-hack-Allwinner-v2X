Camera hotspot

The camera can provide a WiFi hotspot with an optional WPA2 password. Camera sign-in stays enabled. Connect to , then open http://192.168.10.1 (use your configured web port if different). The hotspot provides local camera access, without Internet sharing.

Use rear reset button for hotspot Enabled by default on supported firmware. Hold five seconds to clear the hotspot password and start an open hotspot instead of a factory reset. Short presses are ignored.

Save the hotspot settings before starting it. Starting the hotspot disconnects the camera from its current WiFi. Returning to primary WiFi uses the saved primary credentials. A temporary hotspot ends on reboot unless the boot option is enabled.

Primary outage grace period Seconds to allow the primary WiFi to reconnect before maintenance takeover (30-3600).

After maintenance takeover, the camera uses a maintenance-only wpa_supplicant profile and DHCP. It will not retry the primary SSID until the next reboot, avoiding continuous multi-network polling. If the maintenance network also fails six consecutive recovery attempts, the camera reboots and starts again with the primary profile.

Any WiFi configuration change will take effect after reboot.
