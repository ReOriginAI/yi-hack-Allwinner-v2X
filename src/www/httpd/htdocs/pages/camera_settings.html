Scene grades texture complexity (0–2), Move grades motion complexity (0–4), and MovingLevel grades scene-change intensity (0–3). BinImgRatio is the percentage of 8×8 blocks whose difference score exceeds MovingTh. These vendor summaries do not identify objects. With masking disabled, custom start thresholds use BinImgRatio and presets can also use the stronger MovingLevel hint. With masking enabled, the pink spatial score uses the start/stop thresholds.

This camera offers three firmware sensitivity levels: low, medium, and high. Separate change thresholds and timing controls are unavailable on this firmware.

Video motion metadata: format, extraction and examples

On y28ga, SD recordings retain the event-based yi-motion-v1 object in yi_motion. Its event_columns header is ["offset_ms","unix_ms","state","kind"]; each events row follows that order. State 1 means motion, 0 means idle, and kind distinguishes a transition from a startup observation. initial_state describes the state at clip start; -1 means unknown. history_available and history_truncated describe missing history. Masking changes these events, without adding foreground pixel counts to the MP4. The extraction command below works for both formats.

New y623 SD recordings contain a compact yi_motion JSON tag: one static column header (schema) and an array of raw vendor readings (data). The recorder embeds it while finishing the MP4, and FTP uploads retain it. Run this on your computer with FFprobe and jq:

ffprobe -v error -show_entries format_tags=yi_motion -of json recording.mp4 |
  jq '.format.tags.yi_motion | fromjson' > motion.json
{
  "schema": ["unix_ms", "Scene", "Move", "MovingLevel", "BinImgRatio", "MovingTh"],
  "data": [
    [1791858420000, 0, 1, 1, 2.10, 20],
    [1791858420200, 0, 2, 2, 4.25, 20],
    [1791858420400, 0, 2, 2, 3.80, 20]
  ]
}
ColumnMeaning
unix_msUTC Unix timestamp in milliseconds. Local-time filenames do not shift this value.
SceneVendor texture-complexity grade, documented range 0–2.
MoveVendor motion-complexity grade, documented range 0–4.
MovingLevelVendor scene-change intensity grade, documented range 0–3.
BinImgRatioPercentage (0–100) of 8×8 blocks whose difference score exceeds MovingTh.
MovingThVendor block-difference threshold, documented range 10–31. This is separate from the detector's start/stop percentages.

Rows are captured only while our detector is active, including the reading that triggers START. Each motion starts with five samples about 200 ms apart, including the trigger; later samples are about one second apart until the detector returns to idle. A short motion stops the burst early. Use the actual timestamps because polling and load affect spacing. No idle or pre-trigger readings are added.

Each file includes only readings whose timestamps fall within that video. A clip that starts during an existing motion gets its continuing samples; it does not receive a fabricated trigger. These arrays contain measurements, without inferred motion intervals or object classifications. Gaps can also come from invalid readings. A missing tag means sampling was unavailable or the recorder/container was unsupported; an empty data array means no valid retained active samples matched the clip.

Export the header and all raw rows as CSV:

jq -r '.schema, .data[] | @csv' motion.json

To locate a reading in the video, subtract the video's UTC creation_time from unix_ms / 1000. The video start time has one-second precision. Older recordings and other models may still use the previous yi-motion-v1 object with events and optional levels; existing files are retained.
