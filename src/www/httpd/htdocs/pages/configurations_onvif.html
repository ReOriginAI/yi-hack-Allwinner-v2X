RTSP speaker backchannel
Enable the camera-speaker RTSP backchannel. With go2rtc the speaker helper is started only while a client has an active talkback session, so there is no resident backchannel process while idle. This is independent of the ONVIF server and remains available when ONVIF is disabled. ONVIF, when enabled, advertises the same capability. Changes to this setting are applied immediately.
